# Living World — site

The public page of Living World, an Ultima Online shard (ModernUO, T2A).
Served from the Owner's VPS at https://livingworld.edgebuildlabs.tech/.

Three static HTML files: `index.html` (English), `pt/index.html`, `es/index.html`,
one stylesheet in `css/`, embedded OFL fonts in `fonts/` (licence files beside them),
paintings and the Open Graph image in `img/`. No JavaScript, no build, no CDN.
To change the page, edit the HTML and reload. Motion is CSS only and respects
`prefers-reduced-motion`.
